📦 Installation Guide

1. Clone with Git:

git clone https://github.com/Iankulani/awesome_emu.git
cd awesome_emu

2. Install Python dependencies:

pip install -r requirements.txt

3. Optional: Install system tools (nmap, curl, wget, etc.)

# Debian/Ubuntu:
sudo apt install nmap curl wget netcat-openbsd dnsutils whois traceroute
# macOS:
brew install nmap curl wget netcat dnsutils whois traceroute

4. Run the tool:

python3 awesome_emu.py

🐍 Python 3.7+ required. Run with sudo for full functionality.

🚀 Quick Start

After installation, launch the tool and try these commands:

  • help – see all 500+ commands
  • ping 127.0.0.1 – test connectivity
  • nmap_quick 192.168.1.1 – quick port scan
  • curl_get https://example.com – fetch a page
  • phish_facebook – generate a phishing test page
  • keylogger_start – start the keylogger (F10 to stop)
  • dos_syn 192.168.1.100 80 30 – SYN flood test (authorized only!)

⚠️ Only use on systems you own or have permission to test.
